# ドパミン・モール

永遠に登れるショッピングモールがダンジョンのローグライクRPG（開発中）。

## 世界観

世界は、ほぼ今と一緒の近未来の日本。ダンジョンは、永遠と登れるショッピングモールみたいな施設。
モールは高い階に行くほど、刺激的なアトラクションやアイテムやイベントが発生する。
ドパガキな主人公は、より刺激を求めて短絡的にモールの上の階を目指す。

敵は、モールの下の階層は店員や客。少し上っていくと、着ぐるみや動物展示から逃げ出した動物が現れる。
さらに上の階には何がいるのか、誰も知らない。上の階には何があるのか、誰も知らない。

## 操作方法

- ゲームパッド（十字キー + A/B/X/Y + L/R + Start/Select）
- Fire TV リモコン（十字キー）

## 遊び方（M2：ダンジョン生成とターン制移動）

- フロアは5種類のタイプ（テナントフロア／スーパーフロア／ゲームセンター／フードコート／イベントフロア）から、階数で候補を絞ってランダムに選ばれる。
- 1フロアは画面より広く、カメラがプレイヤーを追ってスクロールする。
- 緑のエスカレーターと青の非常階段に乗ると、次の階へ進む（基本は一方通行の上り）。
- 行ったことのある部屋と通路だけ明るく見える。未踏の場所は暗いまま。
- Mキーでミニマップ（オーバーレイ表示）の表示／非表示を切り替える。通った道だけ表示される。
- 移動は1マスで1ターン。スペースキー／ピリオドキーで待機（1ターン過ごす）。
- HUD には現在の階数とフロアタイプ名、ターン数が表示される。

## 遊び方（M3：敵と戦闘）

- 敵は3種類。客（弱い・数が多い、記号 'c'）、店員（普通、記号 's'）、警備員（強い・たまに出現、記号 'G'）。
- 敵のいるマスへ移動しようとすると、その場でぶつかり攻撃をする。ダメージは攻撃力−防御力（最低1）。
- 敵のHPが0になると倒れて消える。階が上がるほど敵の数と強さが少し増える。
- 敵はプレイヤーの1ターンごとに1回行動する。プレイヤーが5マス以内にいると近づいてくる。それ以外はランダムにうろつく。
- 敵に隣接されると攻撃される。HUD にプレイヤーのHPが表示される。
- HPが0になるとゲームオーバー。Enterキーで最初からリスタートできる。
- ミニマップには敵の位置が赤い点で表示される。

## 遊び方（M4：アイテムと装備）

- アイテムは3系統。回復（ドリンク HP+10／おにぎり HP+15／スイーツ HP+25、記号 '!'）、武器（傘 攻撃+2／フライパン 攻撃+4、記号 '/'）、防具（エプロン 防御+1／ジャケット 防御+2、記号 ']'）。
- フロアに数個ランダムに配置される（1階で4〜6個、階が上がるごとに少し増える）。
- アイテムのあるマスに移動すると自動で拾う。持ち物は最大10個で、いっぱいのときは拾えず、その場に残る。
- Iキーで持ち物一覧（オーバーレイ表示）を開く。もう一度Iキーで閉じる。開いているときに数字キー（1〜0）でアイテムを選ぶと、回復アイテムなら使ってHPが回復し、武器・防具なら装備する。装備は武器・防具を1つずつ。交換すると古い装備が持ち物に戻る（持ち物がいっぱいの場合は交換できない）。
- アイテムを使う・装備する・拾う操作は1ターン消費する。一覧を開く・閉じるだけではターンを消費しない。
- HUD には攻撃力・防御力と、装備中の武器・防具が表示される。

## 遊び方（ゲームパッド・Fire TV リモコンでの持ち物操作）

- コントローラー拡張は使っていない。ゲームパッド・Fire TV リモコンのボタンは Android のキーコードとして届く（タイトル画面の Aボタン開始と同じ仕組み）。
- Start ボタンまたは Y ボタンで持ち物一覧を開く（Iキーでも開ける）。
- 一覧が開いているときは十字キー（上下）で項目を移動する。選んだ項目は黄色くハイライトされる。端まで行くと反対側に折り返す。
- Aボタンまたはリモコンの決定ボタンで、選んだアイテムを使う／装備する。キーボードでは数字キー（1〜0）での直接選択もできる。
- Bボタンまたはリモコンの Back ボタンで一覧を閉じる（Iキー・Start／Yボタンでも閉じられる）。
- 一覧を開く・閉じる・項目を移動するだけではターンを消費しない。使う・装備する操作は1ターン消費する。
- ゲームオーバー画面では Aボタンまたは決定ボタンでもリスタートできる。

## 遊び方（M5：階層テーマとボス）

- 階数で敵の顔ぶれが変わる。1〜4階は下層（客・店員・警備員）、5〜9階は着ぐるみと動物（クマの着ぐるみ 'b'／ウサギの着ぐるみ 'r'／逃げ出した犬 'd'／逃げ出したサル 'm'）、10〜14階はUMA（ツチノコ 't'／雪男 'Y'）、15階以上は天界の存在（天使 'A'／獅子の神 'L'）。階が上がるほど敵の数と強さが増える。
- HUD に現在の階層テーマ名（LOWER MALL／MASCOT & ANIMALS／UMA／CELESTIAL）が表示される。
- ボスフロア（5階ごと）：その階層を代表するボスが1体いる（5F 店長／10F 巨大着ぐるみ／15F〜 大天使）。ボスは金色で大きく表示され、記号は 'B'。HPは通常敵の約5倍、攻撃は約1.5倍と強力。倒すと良いアイテム（フライパン／ジャケット／スイーツのいずれか）をその場に落とす。倒さなくても階段で次の階へ進める。
- モンスターハウス：フロアごとに10%の確率で、ランダムな場所に敵が6〜10体詰まっている。入ると「Monster house!」のメッセージが出る。中の敵は入るまで見えない（視界ルール通り）。

## 遊び方（M6：音楽・演出・グラフィックス）

- タイトル画面：起動すると「DOPAMINE MALL」のタイトル画面が出る。Enterキー／タップでゲーム開始する。ゲームパッドのAボタンでも開始できる。
- BGM：生成チップチューンのループが3曲流れる。タイトル画面は明るくノリのいい曲、ダンジョンは控えめな環境音楽、ボスフロアとモンスターハウスでは緊迫感のある速い曲に切り替わる。ボスを倒すかモンスターハウスの中の敵を倒しきるか、そのフロアを出るとダンジョンの曲に戻る。Nキーでミュートのオン／オフを切り替えられる。曲は `tools/generate_music.py`（Python 標準ライブラリのみで矩形波・三角波を合成）で作った WAV を OGG に変換したもので、`android/assets/music/` に置いてある。デスクトップ版の jar にも同じ音源が入っている。
- 店内放送：HUD に「PA:」で店内放送の文言が流れる。フロアタイプごとに内容が変わる（テナントフロア「本日はご来店ありがとうございます」／スーパーフロア「本日の特売はお惣菜コーナーです」／ゲームセンター「新台入荷しました」／フードコート「フードコートはごゆっくりどうぞ」／イベントフロア「ただいまイベント開催中です」）。階を上がったときは「○階へようこそ」の特別な放送が流れる。放送は20ターンごとに切り替わる。
- 演出：フロアアップ時にプレイヤーの周りに金色のきらめきが散る。攻撃したときは画面が黄色く、敵に攻撃されたときは赤く一瞬光る。敵を倒すと倒れた場所に敵の色の点が散って消える。プレイヤーの周りには柔らかい光がにじむ（視界のルールは変わらない）。どれも軽い実装。

## グラフィックス（ドット絵スプライト＋2D演出）

- 描画は2Dスプライト。トルネコや風来のシレンのようなレトロなドット絵をベースに、光や霧、パーティクルなどの最先端の2D演出を組み合わせている。
- タイルセットは `tools/generate_tiles.py`（Pillow）でプログラム生成した 32x32 のドット絵 PNG（`android/assets/sprites/`、全34枚）。床3種、壁、棚、ゲーム筐体、テーブル、カウンター、ステージ、観客席、エスカレーター、非常階段、プレイヤー、敵14種、アイテム7種。
- 階層別の雰囲気：下層（1〜4階）は明るく暖かい現代のショッピングモール。中層（5〜9階）はやや落ち着いた光。上層（10〜14階）は暗めで霧が漂う。最上層（15階以上）は暗い通路にランタンの暖かい光と霧が漂う神秘的な雰囲気で、プレイヤー周辺の光も強くなる。行った場所だけ明るく見える視界のルールは変わらない。
- 移動はターン制のまま、プレイヤーと敵がマスからマスへ約0.12秒で滑らかに移動する。プレイヤーは歩行時に小さく上下に跳ねる。

## 言語対応（英語・日本語）

- ゲーム内の表示は英語と日本語の2言語に対応している。タイトル画面、HUD、店内放送、メッセージ、持ち物一覧、ゲームオーバー画面、フロアタイプ名、階層テーマ名、敵とアイテムの名前まで、すべて両言語で表示できる。
- 起動時は端末の言語設定で自動的に決まる（端末が日本語なら日本語、それ以外は英語）。タイトル画面で **Lキー**を押すと英語と日本語を切り替えられる。切り替えた言語は保存され、次回起動時もそのままになる。
- 日本語の表示には Noto Sans JP のフォントを使っている。フォントファイルは `android/assets/fonts/NotoSansJP-subset.ttf` にあり、ゲームで使う文字だけに絞ったサブセット版（約171KB）だ。元のフォントは Google Fonts の Noto Sans JP（SIL Open Font License 1.1）で、ライセンス文は同じフォルダの `OFL.txt` にある。サブセット化の手順は `tools/subset_font.py` を参照。
- フォントが読めない環境では英語表示に切り替わる。

## APK の入手方法（Fire TV Stick で遊ぶ）

1. GitHub の [Releases](../../releases) ページを開く。
2. 「ドパミン・モール 日次ビルド」（タグ `nightly`）の `dopamine-mall-debug.apk` をダウンロードする。
3. Fire TV Stick の「設定」→「マイ Fire TV」→「開発者オプション」で「不明なアプリのインストール」を許可する。
4. Downloader アプリなどで APK をダウンロードしてインストールする。
5. ゲームパッドまたは Fire TV リモコンで遊ぶ。

## デスクトップ版の入手方法（PC で遊ぶ）

テストプレイ用の PC 版です。Android 版とゲーム内容は同じソースコード（core モジュール）で、起動部分だけが違います。

1. GitHub の [Releases](../../releases) ページを開く。
2. 「ドパミン・モール 日次ビルド」（タグ `nightly`）の `dopamine-mall-desktop.jar` をダウンロードする。
3. Java 17 が入った PC で、次のコマンドで起動する。

```sh
java -jar dopamine-mall-desktop.jar
```

4. キーボードの矢印キー / WASD で遊ぶ。

## 開発

- エンジン：libGDX 1.12.1（Java）
- 対象：Android（minSdk 21 / targetSdk 34）。Fire TV Stick 4K Max（第2世代、32bit・Fire OS 8・RAM 2GB）対応のため armeabi-v7a を含む。テストプレイ用のデスクトップ版（LWJGL3、ウィンドウ 1280x720）もあり、ゲーム内容は core モジュールを共有している。
- 日次ビルド：GitHub Actions が毎日 00:00 UTC（日本時間 9:00）に APK とデスクトップ版 jar をビルドし、`nightly` リリースを更新する。`main` への push 時と手動実行（workflow_dispatch）でもビルドされる。

### ローカルビルド

```sh
# JDK 17 と Android SDK（platform 34 / build-tools 34.0.0）が必要
./gradlew :android:assembleDebug
# APK: android/build/outputs/apk/debug/android-debug.apk

# デスクトップ版（Android SDK は不要、JDK 17 のみ）
./gradlew :desktop:dist
# jar: desktop/build/libs/dopamine-mall-desktop.jar
# 起動: java -jar desktop/build/libs/dopamine-mall-desktop.jar
```

`local.properties` に `sdk.dir=/path/to/Android/Sdk` を書くこと。
